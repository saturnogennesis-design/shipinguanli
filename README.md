# 公司短视频内容中台 · V3.19（测试验收版）

本版将业务工作空间改为“项目”，发布流向改为独立的“发布目标账号”。不再维护平台、店铺或具体平台账号这一层。

## 页面结构

系统外层：系统首页、通知公告、工作报备、项目管理、组织与权限、报备模板、配置中心和操作日志。

进入项目：项目工作台、素材中心、项目产品库、内容池、审核中心、发布管理、版本管理和数据统计。菜单仍受员工权限与项目职责约束。

维护项目：在“项目管理 → 维护项目”集中设置基本信息、业务分类和发布目标账号。小组与权限关系继续在外层“组织与权限”维护，不再展示独立的内容小组页面。

同一员工可以进入多个获授权项目。每次切换项目都回到新项目工作台，不保留旧项目的模块、详情、弹窗、筛选和勾选。不同浏览器标签页的项目状态独立。

## 业务规则

- 项目的产品库、素材、内容、小组、业务分类及发布业务相互隔离。
- 视频／图文表示文件格式；产品展示、口播、剧情、测评等业务分类由每个项目独立配置。
- 发布目标账号在“项目管理 → 维护项目 → 发布目标账号”配置，分别归属项目。一条内容可以点亮多个目标账号灯。
- 多人可以操作同一条内容的不同目标灯；同一目标的过期提交会被拒绝，修改与灯状态均保留操作人、时间和日志。
- 发布商品选填，默认带入原内容产品，可以更换或取消；仅影响当前目标发布资料，不改动原内容关联。
- 工作报备只保留日报，放在外层，不限制收发人员所属项目。发送人是当前员工，接收人手动选择，抄送和附件访问沿用日报权限。
- 日报支持 Word、Excel、PDF 附件，入口为“＋ 上传附件”。旧版 .doc／.xls 预览需要服务器本地安装 LibreOffice；不使用外部在线转换服务。

## 旧数据处理

本次确认的现有业务全部归入“十乐”。产品、素材、内容、版本文件、人员及日报关系保留。

旧发布灯退出新流程，不转换为新目标账号；首次进入新发布管理时目标列表为空，请由管理员重新配置。

项目化升级文件包括 `0033_publishing_product_master.sql`、`0034_projects_and_targets.sql` 和 `0035_target_metrics.sql`。V3.19 新增 `0036_target_lamp_appearance.sql`，仅为现有发布目标增加灯内文字和颜色字段。应用首次访问数据库会自动执行待执行的 SQL。正式数据升级前应使用正式数据库备份进行独立验收，不能用开发测试数据库替代。

## 开发与验证

要求 Node.js >=22.13.0、pnpm 11.19.0。每个云端任务已有独立工作区，直接使用现有检出，不需要额外 Git worktree。

安装依赖：`pnpm install --frozen-lockfile`。

开发运行前，将 `ORBIT_DB_PATH`、`ORBIT_MEDIA_DIR` 设置为独立的开发数据库和媒体目录，再运行 `pnpm dev --hostname 127.0.0.1`。不要指向正式系统的数据或媒体目录。

验证命令：

```sh
pnpm exec tsc --noEmit
pnpm run build
pnpm run test:projects
```

接口验收脚本 `tests/projects.e2e.mjs` 要求 `ORBIT_E2E_BASE_URL` 指向全新、隔离的测试服务，并检查初始化状态。最新配置、发布操作、浏览器及跨项目验收详见 [V3.18-展示恢复与发布配置验收说明.md](V3.18-展示恢复与发布配置验收说明.md)。

历史 V3.0–V3.16 文档保留供参考。涉及项目、平台、发布账号和口播报备的规则，以本版说明为准。

## V3.18 已完成的变更

以项目化大改前 V3.16 的展示为基准，复用原列表、筛选、卡片、详情分区、按钮及配色；项目配置和发布目标按用户确认的项目化方案处理。未来页面调整也沿用此约定，见 [AGENTS.md](AGENTS.md)。

发布列表恢复缩略图与详情入口；单条灯直接点亮，关闭灯二次确认。表格上方按同一目标提供批量点亮，确认后统一提交，冲突时整批回滚。筛选支持原内容关联商品、上传人和业务分类组合使用，不把发布资料更换的商品算作原内容商品。

验证结果、页面对照和下载版本状态见 [V3.18-展示恢复与发布配置验收说明.md](V3.18-展示恢复与发布配置验收说明.md)。该轮未增加数据库升级文件，未部署到正式系统。

## V3.19 本轮变更

发布列表标题最多两行，商品缩略图下显示截断名称，点击可查看原图。灯只显示灯内文字，不再显示后方名称；在项目维护中可配置灯内文字、点亮颜色，并实时预览点亮／未点亮效果。

公共缩略图按可见区域加载，图片服务生成不超过 320×320 的 WebP 并缓存，重复请求可走私有条件缓存，仍先校验权限。历史无封面视频按需生成小封面，同一浏览器最多同时生成两个；大图和原视频只在预览时按需读取，视频封面生成属于受控例外。原图与原视频不改写。

Sharp 0.34.5 从已有间接依赖提升为明确的运行依赖；依赖版本固定在 lockfile，依赖安装仍以 `pnpm install --frozen-lockfile` 为准。详细升级、验证及测试范围见 [V3.19-发布灯与缩略图验收说明.md](V3.19-发布灯与缩略图验收说明.md)。本版仍为测试验收版。
