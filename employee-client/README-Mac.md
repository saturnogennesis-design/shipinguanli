# 员工端1.4.0：主机集中处理同步问题

先更新主机至V3.36.0，再使用原电脑账号运行本包的更新入口。此次新增本地同步模块，旧版自动更新清单不包含它，因此Windows和Mac均需手动更新一次；不卸载、不删除data、不清除待同步附件。仅通过浏览器访问主机的员工无需安装本地包。

主账号的“员工同步管理”可以查看每台电脑报告、当前待同步内容、本地摘要、主机版本及处理结果。旧员工端不会上报；离线电脑显示上次报告，不能当作实时正常。处理指令在编辑／上传结束并再次确认页面活动后执行，不强制刷新表单。采用主机版本会保留本地正文和附件，旧修改不再自动上传；彻底清理备份另行二次确认。

每日沿用回执核对，每三天空闲时重新核对本机近期缓存与主机资料元数据；不自动强制覆盖冲突，不下载全部历史附件。下方同步提示区分待上传、需要核对、已保留备份，支持查看及导出本地内容。主机已接收的任务可核销误报，不能以电脑时间判断覆盖。

此版已在Linux临时环境验证员工运行程序与浏览器联动、指令回传及数据保留；未在真实Windows／Mac执行安装或升级。先选一台电脑验收，再逐步更新其他员工。

# Mac员工端 1.3.0

主机先更新V3.28.0。Apple Silicon（M1／M2／M3／M4等）选arm64包，Intel Mac选x64包；要求macOS 13.5或更新。完整解压保留runtime目录，首次运行InstallEmployee.command，升级运行UpdateEmployee.command。自带官方Node.js 24 LTS，无需另装Node.js、Homebrew或下载依赖。旧1.0版须用本完整包升级一次。

安装在当前用户的Library/Application Support/OrbitEmployee，程序位于个人Applications/Orbit Employee.app，后台由当前用户LaunchAgent启动。更新保留data及待同步文件。没有Apple签名和公证；如系统拦截，请按macOS标准“隐私与安全性／仍要打开”确认信任，不要关闭Gatekeeper。首次需联网访问主机并正常登录完成初始缓存。

打开Orbit Employee后，首次填主机根地址，后续直接使用原系统页面：原登录、项目导航、列表、详情、上传、保存与提交。没有独立离线上传工作台。主机仍用原网页版。

跨境资料、短视频图文／视频、素材中心的新增、编辑文件与提交先可靠保存本机；主机关机或断网时排队，连接恢复后自动传输并执行已点击的提交，无需再次提交。短视频退回后新版本沿用原入口。底部仅显示同步状态和需要处理的异常；“本机待同步”不代表主机已收到。冲突保留本机内容，不能静默覆盖主机新版本。审核、配置、归档删除、单独追加备注等实时操作仍需连接主机。

开机登录后后台拉取近期有权限资料，每分钟检查，默认限速512KB/s。近期资料每类最多100条；自动缓存小图，查看过的原文件进入后台缓存，未缓存文件离线不能播放。历史文件约5GB按最近使用淘汰；未同步附件另计、绝不因缓存满而自动删除。关闭网页仍同步，电脑关机／休眠时不运行。主机必须开机并运行服务才能接收数据。首次同步完成后才能冷启动离线页面。

按主机和员工账号隔离，离线许可7天，联网重新验证权限；普通成员和项目长可见范围沿用主机。本机目录权限保护不等于防本机管理员的加密，勿手工清理data。HTTPS支持校验自动更新，HTTP局域网用完整包升级。

已验证双芯片运行环境校验、安装目录与脚本生成、包内执行权限和Linux上的离线业务流程；未在真实Mac运行安装或签名公证。先在一台匹配芯片的Mac验收，再分发。

1.2每天首次成功连接自动核对主机回执及已完成上传文件是否缺失；本机副本仍在时补传原字节，不重建资料或再次提交审核。无法修复时提示恢复备份。超过1天待上传会提示积压；这不代替备份，也不承诺双方未同时在线时完成传输。主机3.27的分配移交、紧急程度、永久删除需要联网并校验当前版本。

1.3支持进入业务页面主动读取主机最新数据；主机不可达则用缓存，权限拒绝不显示旧缓存。已同步完成的本机编号打开最新主机记录，返回来源保留筛选和位置，不覆盖未保存编辑。本次需配合主机3.28页面更新。
