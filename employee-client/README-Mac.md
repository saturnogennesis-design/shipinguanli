# Mac员工离线端1.0.2（测试版）

需要macOS 13.5及以上。Apple芯片用Mac-arm64包（M1/M2/M3/M4等），Intel用Mac-x64包。可在苹果菜单→关于本机确认芯片。两种包均包含经Node.js官方校验值核对的Node.js 24 LTS原生运行环境及许可证，不需要Homebrew、另装Node.js或管理员权限。

## 安装

1. 主机先具有V3.25.0同步支持，主机仍用原来的网页版；已更新的主机不必再次安装。
2. 完整解压对应芯片ZIP，保留runtime目录，双击InstallEmployee.command。
3. 系统可能要求确认打开下载的安装脚本。可先核对下载来源和SHA-256，再按macOS“隐私与安全性”提示确认允许本次打开；本测试包尚未做Apple公证。不要关闭Gatekeeper或全局修改安全设置。企业策略禁止运行时请联系设备管理员。
4. 安装后从个人Applications中的Orbit Employee打开，默认浏览器显示127.0.0.1:3199。本机服务只监听回环地址，填主机地址、员工账号登录。新账号先在原系统修改首次密码。
5. 已有Mac员工端更新用UpdateEmployee.command，不清除本机缓存及待上传任务。以后登录Mac时后台自动启动，关闭浏览器仍可同步；首次安装会打开页面。

程序放在~/Library/Application Support/OrbitEmployee/app，运行环境放在同目录runtime/v24…，本机缓存、加密会话及上传队列位于data。后台启动项为~/Library/LaunchAgents/com.orbit.employee.plist，日志位于~/Library/Logs/OrbitEmployee。使用用户级LaunchAgent，不修改系统PATH，不安装主机数据库。请不要用清理软件删除data，特别是还有待上传资料时。

## 离线与同步

首次联网登录同步后，可在主机关机时打开本机近期资料、填写新草稿并保存附件；恢复连接后按1MB分块续传，完整校验后生成草稿，不自动送审、不覆盖旧内容。上传队列独立保存，不能被5GB历史文件缓存淘汰。离线查看期限7天，到期须联网重新登录。

每项目最多同步100条有权限的正常内容：跨境线索、母版、产品，短视频内容池。每分钟检查更新，默认512KB/s限速；自动缓存近期小图，大图、视频、文档需点击“保存离线”。只有缓存完成的文件可离线查看。5GB上限只计算历史文件，元数据少量另计，未上传附件另计且不会自动删除。

权限、主机身份和账号分区沿用Windows员工端。权限撤回在恢复连接后处理；离线期间无法即时撤权。审核、管理、通知、报备和素材中心仍在线使用。主机和客户端更新都保留原有业务数据；Mac无需安装Windows主机包。

安装与更新脚本没有在真实Mac上执行。已做Shell语法检查、安装布局／权限／路径转义测试、既有客户端单元回归和包内／官方运行环境校验；无法替代Mac实机运行验证。请先在一台Mac试用。支持的最低macOS版本取自官方Node.js 24运行环境要求。
