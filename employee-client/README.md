# 员工离线端 1.0.0（Windows测试版）

主机先更新到V3.25.0，员工电脑首次运行InstallEmployee.cmd；已有员工端运行UpdateEmployee.cmd。员工电脑需Node.js >=22.13；不需要安装主机数据库或主机服务。安装无需管理员权限，在当前Windows账号下运行。未在Windows实机验证安装脚本，请先用一两台测试电脑试用。

桌面“Orbit Employee”打开本机127.0.0.1:3199页面。填主机根地址，例如http://192.168.1.165:3000，在线登录员工账号。新账号先在原系统修改首次密码。首次联网同步后，主机关机仍可打开桌面快捷方式查看已缓存资料、保存新草稿。Windows登录30秒后启动后台同步，不会自动弹页面；退出网页不会停止后台。每分钟检查一次，默认512KB/s，可暂停或调整限速。

历史范围：同步有权限项目中最近100条正常内容的文字及详情；跨境线索、母版、产品以及短视频内容池。自动缓存近期小图片，每轮最多8MB；大图、视频、文档在详情中点击“保存离线”。只有缓存成功的文件可离线观看，未缓存文件不会显示为可离线播放。不缓存通知、报备、素材中心、归档或回收站；审核与配置仍使用原在线系统。本机缓存变旧时显示上次同步时间。缓存限额约5GB（文件），元数据少量另计；按最近访问清理，清理不删除主机文件。

新增：选择项目、资料类型和来源／商品，填写内容并选择附件，保存后复制至本机待上传区。上传只新建草稿，不自动送审、不覆盖任何旧资料。跨境来源在服务器重新校验；失效来源或权限变化显示“需要处理”。短视频支持MP4/WebM及JPG/PNG/WebP/GIF，跨境类型限制沿用主机。上传分块续传与完整SHA-256校验，同一任务重复提交只生成一条草稿。图片/文档每块1MB、视频相同。未完整保存的任务可“补全附件”，需要重新选择原附件。

待上传附件单独存放，不包含在5GB清理范围；空间不足提示并保留已有附件，不会自动删除。已完成任务也保留本机附件，确认主机收到后可手动“清除本机副本”。不要手动清理data、重装Windows或使用清理软件删除本地文件。没有主机备份前，本机待上传文件并非备份。

账号：按主机固定身份和员工ID分区。不同员工登录看不到前一个员工的缓存；退出账号隐藏缓存但保留队列。离线许可7天，到期须在线重新登录。权限撤回在下次联网验证后清理不可见历史，不丢待上传队列；断网时无法即时获知撤权。缓存通过Windows账号目录权限保护，同一Windows账号的其他程序仍可能读取本机内容，不是对本机管理员的加密防护。登录密码不保存，会话加密保存；加密密钥和缓存同属当前Windows用户。

更新：主机用主机包，员工端使用单独员工包。HTTPS连接支持从同一已认证主机自动检查、校验并更新员工程序；失败回退上一启动版本。HTTP局域网不自动下载执行程序，使用UpdateEmployee.cmd人工更新。任何员工端更新都保留data目录。远程访问接入HTTPS后可沿用协议；更换地址需重新登录，主机身份相同则仍识别原账号和待上传任务。手机端本版未实现。
