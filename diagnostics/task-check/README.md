# 主机任务只读核对工具

无需安装或更新系统。将三个工具文件放到主机系统安装目录（与package.json、deploy目录同级），双击ExportTaskCheck.cmd。

生成同目录task-check-日期时间.json。请将该JSON发回以核对任务关联；不需要提供整库、附件或账号密码。

只读取“月光峡谷”跨境项目的任务、资料编号／名称、审核状态、人员显示名、版本来源关系及文件数量。不导出文件本体、文件路径、正文、备注、密码或登录令牌。不调用业务初始化、迁移、任务同步、修复或删除逻辑。无网络传输。

如果工具不在安装目录，会要求输入主机安装路径。配置采用单引号路径格式，由原安装程序生成；无法识别时停止，不猜测数据库位置。主机Node运行环境沿用已安装系统配置。

命令行也可运行：node export-task-check.mjs --db 数据库路径 --install-dir 系统目录 --output 新建报告.json。存在同名输出时停止，不覆盖。项目重名时可传--project-id准确指定。

Linux临时数据验证不代表Windows实机已验收。本工具只用于核对，不会自动取消任务或合并作品。
